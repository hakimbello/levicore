# Levi Core

Levi Core is an AI software engineering operating system designed to help a solo builder plan, understand, modify, validate, and finish software projects with persistent project memory, strict scope control, and model-independent execution.

## Current Phase

M0: Product and Scope Lock

No implementation code is approved until the foundation documents are complete and approved.
