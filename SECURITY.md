# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting for this repository when available.

Do not open a public issue for unpatched vulnerabilities, suspected credential exposure, or reports that include exploit details.

If private vulnerability reporting is not available, open a minimal public issue that states a security report is available and avoid including sensitive details. A maintainer will provide a private coordination path.

## Scope

Security reports for LeviCore source code, Levi Desktop, Levi VS Code extension code, release workflows, packaging, and repository exposure are in scope.

Please do not test against systems, accounts, or workspaces you do not own or have explicit permission to assess.
